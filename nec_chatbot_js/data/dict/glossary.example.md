# 用語辞典（ひな形）

実データの `glossary.md` はサークル内部資料のためリポジトリに含めていません。
このファイルと同じ書式で `glossary.md` を用意すると、用語注入が有効になります。

書式のルール

- `##` 見出しが用語。別名は `・` または `、` で区切って並べる
- 見出しの次の行から次の見出しまでが定義文
- 1文字の語は誤爆しやすいため、2文字以上で登録する

質問文に見出しの語が含まれると、その定義文が検索クエリに連結されます。
「その組織でしか通じない略語」を埋め込みモデルに理解させるための仕組みです。

## 略語A・略語Aの別名
略語Aが何を指すのかを、資料本文と同じ言い回しで説明する文章。検索時はこの文が
質問に足されるため、定義文に含まれる語がそのまま検索の手がかりになる。

## 略語B
同上。用語ごとに `##` 見出しで区切って並べていく。
